Ficha técnica: Git

¿Qué es?

Git es un sistema de control de versiones distribuido que permite guardar el historial de cambios de un proyecto y trabajar en equipo sin pisar el trabajo de los demás.

Se suele usar junto con plataformas como GitHub y desde un IDE como Visual Studio Code.

Datos principales

Creador: Linus Torvalds.

Fecha de lanzamiento: 7 de abril de 2005.

Versión actual: rama 2.x.

Comandos básicos

Para guardar los cambios en el repositorio se usa:

git commit -m "mensaje del commit"

Y para subirlos a GitHub:

git push origin main

Atajo útil

En Visual Studio Code puedes guardar el archivo antes de hacer el commit pulsando Ctrl + S.

Nota

Cada commit se identifica con un código SHA-1 de 2160 combinaciones posibles.
