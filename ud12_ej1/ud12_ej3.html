Ficha técnica: Visual Studio Code

Descripción

Visual Studio Code es un editor de código fuente, es decir, un programa pensado para escribir y modificar el código de las aplicaciones. Aunque no es un IDE completo, gracias a sus extensiones se puede usar con lenguajes como HTML, Java o Python.

Datos generales

Desarrollador: Microsoft.
Primera versión estable: 14 de abril de 2016.
Sistemas operativos: Windows, Linux y macOS1.

Uso básico

Para abrir la carpeta actual desde la terminal se usa el comando code .

Para guardar un archivo pulsa Ctrl + S, y para abrir la paleta de comandos pulsa Ctrl + Shift + P.

1 También existe una versión que funciona directamente en el navegador.
